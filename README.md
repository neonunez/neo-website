# neo-website

A personal portfolio website. Feel free to adapt it to your own case.

## Use it as your own

Fork it. Change the text. Swap the projects. Make it yours.

Built with:
- React + TypeScript
- Tailwind CSS
- Vite
- Framer Motion
- Wouter

## Deploy

```bash
npm install
npm run dev
```

```bash
npm run build
```
